# 知到倍速助手（实验版）

这是一个 Android 实验工具，尝试通过 Android MediaSession 向当前媒体会话发送 2×、2.5×、3×、4× 播放速度请求。

## 重要限制
- 工具不会修改知到 App 内部代码，也不会绕过账号、课程或平台权限。
- 只有当知到播放器公开媒体会话并接受外部播放速度控制时，倍速请求才可能生效。
- 能检测到媒体会话，不代表知到一定接受倍速控制。
- 未在华为 MatePad / HarmonyOS 4.2.0 上实机验证，不能保证有效。

## 构建
在 GitHub Actions 页面手动运行 “Build Android APK” 工作流。
